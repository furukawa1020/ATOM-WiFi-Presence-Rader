# ATOM Wi-Fi Presence Radar (PlatformIO / Arduino)

This repository is being developed following an issue-first workflow and PR-based delivery.

Current scope:
- ESP32-S3 based presence detection with Wi-Fi CSI on AtomS3R nodes.
- PlatformIO + Arduino-ESP32 environment.
- TX/Coordinator + 3 RX nodes in a first-phase topology.

To follow the requested process:
1. Create a specific issue for each discrete deliverable.
2. Implement one issue at a time.
3. Submit each issue implementation as an independent PR.

See [docs/issue-pr-workflow.md](docs/issue-pr-workflow.md) for the first issues.
