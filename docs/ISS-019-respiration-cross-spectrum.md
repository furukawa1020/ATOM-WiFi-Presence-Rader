# ISS-019 呼吸微動のクロススペクトル推定

## 目的

呼吸帯域にピークがあることだけでなく、CSI振幅と補正済み位相が同じ周波数で複数時間区間にわたり連動することを確認する。呼吸微動の物理証拠を、周波数、S/N、倍音、クロススペクトルコヒーレンス、リンク一致度へ分解する。

## 長時間履歴

呼吸推定の開始条件を10 Hz要約192点、約19.2秒へ延長する。最大256点、約25.6秒の固定長履歴を使用し、0.12 Hz付近でも複数周期に近い観測時間を確保する。

## 周波数探索

0.12、0.16、0.20、0.25、0.30、0.36、0.42、0.50 Hzについて、振幅主成分と位相主成分のHann窓スペクトルを計算する。両者の合計電力が最大となる候補を基本周波数とする。

出力は0.10〜0.50 Hzを0〜1へ写像した`respiration_rate_normalized`とする。医療上の呼吸数診断値ではなく、CSIで観測した周期微動の周波数である。

## スペクトルS/Nと倍音

- 0.65、0.80、1.00、1.25 Hzの平均電力を帯域外雑音とする。
- 基本周波数ピークと帯域外雑音の比を対数圧縮し、`respiration_spectral_snr`とする。
- 基本周波数の2倍にある振幅・位相電力を`respiration_harmonicity`として独立保持する。

倍音は必須条件ではない。波形の非正弦性や周期外乱を後段で識別する追加情報として使う。

## 大きさ二乗コヒーレンス

最良周波数について、128点のHann窓を履歴の先頭、中央、末尾へ配置する。各区間で振幅係数`A`と位相係数`P`を複素数として求め、次を計算する。

`|sum(A * conj(P))|^2 / (sum(|A|^2) * sum(|P|^2))`

これにピーク周波数一致、帯域内集中度、体動の少なさを連続重みとして掛け、`respiration_coherence`とする。ピーク位置だけが偶然一致する低周波ドリフトを抑えられる。

## 最大3リンク一致

各リンクの品質、呼吸電力、コヒーレンス、S/Nの積を証拠重みとする。最も強いリンクの周波数を中心にロバスト重み付き平均を行い、分散から`respiration_rate_agreement`を算出する。

リンクの一部で呼吸微動が弱くても、証拠の強い同期リンクで推定を継続する。

## 安全上の境界

CSIだけで呼吸停止、心疾患、ヒートショックを診断しない。本出力は、浴室内の周期微動がどの程度観測できているかを示す物理観測量である。

## M5ATOM制約

履歴、区間係数、最大3リンク融合はすべて固定長配列と局所変数で処理する。PC、クラウド、外付けセンサー、追加FFTライブラリは使用しない。
