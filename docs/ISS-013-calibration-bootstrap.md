# ISS-013 起動時成果物の互換確認と一括適用

## 目的

NVSに保存された最新の校正成果物を、現在のファームウェアと設置条件に適合する場合だけ実行系へ反映する。再読み込みに失敗した候補は棄却し、すでに適用済みの成果物と参照データを維持する。

## 実行時フィンガープリント

`CalibrationRuntimeFingerprint`は次の実行条件を表す。

- ファームウェア互換版、特徴処理版、通信プロトコル版
- Wi-Fiチャネルと帯域幅
- 受信ノード数とノードID集合
- 全ノード数と各ノードの設置向き

値が未設定、範囲外、重複ノードID、未確定の設置向きを含むフィンガープリントは、NVSを読む前に拒否する。

## 適用手順

`CalibrationBootstrap::loadAndActivate()`は次の順序で処理する。

1. 実行時フィンガープリントを検証する。
2. CRCと世代管理を通過した最新成果物を`CalibrationStorage`から候補領域へ読む。
3. 版番号、無線条件、ノード構成、設置向きを完全一致で照合する。
4. 時間状態エンコーダの出力スキーマと判定モデルの入力スキーマを照合する。
5. 時間状態モデルと判定モデルを副作用なしで事前検証する。
6. 両モデルを実行系へ適用し、成功時だけ候補成果物を有効領域へ昇格する。

モデル適用APIは事前検証と同じ検証関数を使用する。判定モデル適用が予期せず失敗した場合、すでに有効な成果物があれば時間状態モデルを元へ戻す。

## 公開データと診断

適用成功後は次のデータを読み取り専用ポインタと件数で参照できる。

- 空室ベースライン
- 選択済みサブキャリア
- 共分散下三角要素

`CalibrationBootstrapReport`はストレージ、互換性照合、各モデル適用の段階別結果コード、候補校正ID、現在有効な校正IDと世代を保持する。失敗時にも現在有効な状態を報告する。

## 境界

このIssueでは起動処理の部品とライブラリ接続までを実装する。実機固有のフィンガープリント生成、`setup()`からの呼び出し、画面や通信への診断表示は後続Issueで接続する。
