# ISS-029 外乱別帰無校正プロファイルのNVS永続化

## 目的

ISS-028で学習した7コンテキスト、5危険証拠、合計35個の帰無統計をM5ATOM再起動後も安全に利用する。ストレージ障害や書込み途中の電源断で危険証拠を誤って弱めないことを、単純な保存成功率より優先する。

## 保存形式

固定長プロファイルには次を格納する。

- マジック値
- 形式版
- 構造サイズ
- 世代番号
- 35個の平均、分散、サンプル数
- CRC32

CRC32はCRCフィールドより前の全バイトを対象とする。構造は固定長で、動的メモリや可変長シリアライズを使わない。

## 読込検証

起動後に校正器が最初の有効観測を受けた時点で、NVS名前空間 ctxnull の profile_a と profile_b を読み込む。CSI受信コールバックではなく送信役M5ATOMの通常処理経路で実行する。

各スロットについて次を検証する。

- 保存サイズが現在の構造サイズと一致する
- マジック値、形式版、構造サイズが一致する
- CRC32が一致する
- 平均と分散が有限値
- 平均が0から1、分散が0から1の範囲
- サンプル数が設定上限以下
- 学習済み統計の分散が尺度下限以上

両方が正常なら周回を考慮した世代比較で新しい方を選ぶ。一方だけ正常なら正常側から復旧し、片側復旧を診断出力する。両方が無効なら推測修復せず、未成熟なRAMプロファイルから開始する。

## A/Bチェックポイント

現在のアクティブスロットとは反対側へ次世代を書き込む。書込み後に同じスロットを読み戻し、すべての検証と世代一致が成功した場合だけアクティブスロットと世代を更新する。

保存条件は次の両方である。

- 前回試行から5分以上
- 安全更新が32回以上

チェックポイントは新しいプローブを処理する直前に実行するため、保存対象は前プローブまでに確定した統計だけになる。同一プローブの後着リンク再評価では保存を開始せず、統計と更新数をプローブ前スナップショットへ戻してから再計算する。

## 障害時の動作

読込失敗時は未成熟な生証拠経路を維持する。書込みまたは読戻し検証に失敗した場合は、RAM上の正常なプロファイル、現在世代、アクティブスロットを変更しない。次回試行まで最低保存間隔を空け、NVSへの連続書込みを防ぐ。

ストレージ障害は人物不在、正常、物理観測不能、呼吸微動喪失として扱わない。危険判定と温熱情報の境界も変更しない。

## JSON診断

- profile_generation
- updates_since_checkpoint
- checkpoint_age_ms
- storage_available
- persisted_profile_loaded
- recovered_from_single_slot
- profile_dirty
- checkpoint_ok

## 構成制約

M5ATOM内蔵NVSだけを使用する。PC、クラウド、外部ストレージ、カメラ、外付けセンサーへ依存しない。本機能は医療診断や救命保証ではない。
