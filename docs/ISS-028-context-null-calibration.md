# ISS-028 外乱モード別オンライン帰無校正

## 目的

浴室CSIでは、同じ生証拠値でも空室、通常在室、シャワー、換気扇、水面変動、ドア開閉で誤報の出やすさが異なる。本機能は各状況の安全な通常分布をM5ATOM上で逐次推定し、現在値が通常範囲をどれだけ超えたかを校正済み証拠として追加する。

生証拠は削除せず常に併記する。帰無分布が未成熟、状況が不明、物理観測不能、危険状態のいずれかでは校正を適用しない。

## 固定コンテキスト

| コンテキスト | 選択に使う証拠 |
| --- | --- |
| 空室 | 空室確率と低人体運動 |
| 通常在室 | 在室確率と安定した呼吸微動 |
| シャワー | シャワー状外乱 |
| 換気扇 | 持続周期外乱 |
| 水面変動 | 低速な水面ドリフト |
| ドア遷移 | 短時間のドア過渡 |
| 未知 | いずれの支持も不足 |

外乱候補は最大値で選択し、最低信頼度に達しない場合は空室または通常在室を評価する。いずれも確定できなければ未知とし、学習しない。

## 帰無統計

床上転倒、浴槽内静止、危険姿勢、呼吸微動低下、在室不明の5証拠について、7コンテキストごとに平均、分散、サンプル数を保持する。合計35統計であり、動的メモリを使用しない。

逐次更新では現在尺度の3倍へ残差をクリップする。単発ノイズが平均と分散を急変させることを防ぎながら、最低0.5%の更新率で長期ドリフトへ追従する。尺度には下限を設け、ゼロ分散による過大な標準化を防ぐ。

## 安全な更新ゲート

次の条件をすべて満たす場合だけ帰無統計を更新する。

- 融合後の物理観測が可能
- 総合安全レベルが通常
- 転倒、浴槽内静止、危険姿勢、呼吸微動低下、長時間入浴、危険記憶が低い
- 解析品質とコンテキスト信頼度が閾値以上
- 空室では人体運動が低い
- 通常在室では呼吸微動が安定
- 外乱中は空室または安定呼吸のどちらかが成立

危険な状態を通常分布へ吸収しないことを、適応速度より優先する。

## 校正値

基準の平均と尺度から標準化し、平均から2.5尺度を超えた分を超過度として出力する。48サンプル未満では成熟度だけを出力し、校正値は生値と同じにする。

成熟後も、コンテキストが説明できるという理由だけで生証拠をゼロにしない。低減は最大30%とし、大きな標準化超過がある場合は超過度を優先する。緊急、緊急通知推奨、または高い危険記憶がある場合は危険ロックを有効にし、校正による降格を禁止する。

推奨レベルは既存レベルから一度に最大1段階だけ下げられる。上昇判断と最終ヒステリシスは既存の総合安全層に残す。

## 同一プローブ

新しいプローブを処理する直前に35統計を固定長スナップショットへ保存する。同一プローブの後着リンクで再評価された場合はスナップショットへ戻してから更新し、サンプル数を二重加算しない。

## 技術・知財境界

OpenCSIが示す静穏時尺度、成熟度、環境・端末差の明示という公開された一般原理を参照するが、公開コード、固有式、学習済み値は取り込まない。本実装は一般的なクリップ付き逐次平均・分散と保守的な証拠融合を独自に構成する。

CSI-Benchが示す連続実環境と複数環境での難例評価は、今後の安全な記録済みCSI評価の基準とする。このファームウェアへデータセットや深層モデルは組み込まない。

- [OpenCSI](https://arxiv.org/abs/2607.26665)
- [CSI-Bench](https://arxiv.org/abs/2505.21866)

## 安全境界

本出力は誤報校正のための連続証拠であり、転倒、溺水、無呼吸、ヒートショックの診断ではない。人を転倒させる、沈める、呼吸を止める、危険な長時間入浴を行う校正は禁止する。
