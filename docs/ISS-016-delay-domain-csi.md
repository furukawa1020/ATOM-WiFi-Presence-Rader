# ISS-016 遅延領域CSI強調とサブキャリア信頼度選択

## 目的

浴室の強い静的マルチパスと深いフェージングの影響を減らし、人体による微小な動的反射をM5ATOMだけで強調する。ISS-015の振幅・位相・複素比経路を維持しながら、サブキャリア信頼度と遅延領域の独立観測を追加する。

## サブキャリア信頼度

各サブキャリアについて次の状態を指数移動平均で保持する。

- CSI値の有効率
- 8 bit I/Q値の飽和率
- フレーム間の時間連続性
- 差分位相の雑音分散

これらを0から1の連続重みに変換し、振幅運動量、差分位相、複素比、逐次主成分へ反映する。低品質サブキャリアを一律に削除しないため、一時的なフェージングでも利用可能な情報を残せる。

## 遅延領域処理

1. フレーム中央値でAGCを補正する。
2. 位相アンラップ後に共通位相と線形傾斜を除去する。
3. 補正済み複素CSIを、実在するサブキャリア番号のまま16ビンの非一様DFTへ入力する。
4. 各遅延ビンで静的複素基準、フレーム間差分、雑音分散を逐次保持する。
5. 静的基準からの距離とフレーム間距離を組み合わせ、動的タップだけを強調する。

出力は次の3値に分ける。

- `delay_domain_motion`: 動的遅延タップ全体の運動量
- `delay_spread`: 動的反射が遅延方向へ広がる度合い
- `dynamic_tap_concentration`: 少数の遅延タップへ運動が集中する度合い

## 基準汚染の防止

周波数領域と遅延領域の双方で、初期収集後は静穏時だけ基準を更新する。外れ残差は上限を設けて基準へ反映し、転倒、ドア開閉、シャワー開始などの大きな変化を背景として吸収しにくくする。

## M5ATOM上の計算量

- サブキャリア状態は最大114本の固定長配列
- 遅延領域は16タップの固定長配列
- 1フレーム当たりの遅延変換は最大114 x 16の積和
- ヒープ確保、PC推論、クラウド通信、外付けセンサーは不要

## 融合

追加した4観測量はCRC付きの10 Hz観測パケットへ格納する。送信役M5ATOMは既存の鮮度・系列整合・品質重み・中央値中心ロバスト融合をそのまま適用し、最大3リンクの遅延領域観測を集約する。

## 制約

遅延ビンは校正済みの物理距離そのものではない。帯域幅とM5ATOMのCSI分解能に依存する相対的なマルチパス指標として扱う。床・浴槽などの空間ラベルは、次段で設置位置ごとの校正データを用いて対応付ける。
