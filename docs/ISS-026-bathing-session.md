# ISS-026 入浴セッションと浴槽滞在時間の連続CSI追跡

## 目的

送信役1台、受信役最大3台のM5ATOMだけを使い、入室、洗い場、浴槽境界、浴槽内、退出を一つの連続入浴セッションとして追跡する。総浴室滞在、浴槽滞在、洗い場滞在、境界滞在、未観測時間を実時刻で算出する。

## 7状態モデル

空室、入室中、洗い場、浴槽境界、浴槽内、退出中、占有不明の7状態確率を固定長で保持する。通常時は物理的な隣接状態への遷移を優先し、浴槽から洗い場への直接遷移は強い衝撃証拠に応じてだけ増加させる。

観測には部屋補正済み位置・通常姿勢・呼吸、外乱低減済み人体運動、ドア、水面、測定喪失、転倒時系列を使う。同一プローブ系列へ後着リンクが届いた場合は同じ事前状態から再計算し、経過時間を重複加算しない。

## セッション境界

占有証拠が2秒継続した場合に入室候補時刻からセッションを開始する。空室証拠が5秒継続し、測定品質があり、危険証拠が低い場合だけ退出を確定する。短いドア開閉、瞬間的な位置誤認、リンク喪失をセッション境界にしない。

転倒時系列、危険静止、危険姿勢、呼吸微動喪失が残る間は、観測欠落だけで退出を確定しない。占有か空室かを物理的に区別できない区間は占有不明と未観測時間へ保持する。

## 浴槽区間

浴槽状態が1.5秒継続すると浴槽区間を開始し、洗い場または境界への離脱が1.5秒継続すると終了する。同一セッション内の複数浴槽区間と再入浴回数を保持する。

総セッション時間と浴槽区間は実時刻差で算出する。観測間隔が2秒を超える区間または測定喪失が高い区間は、洗い場や境界へ割り当てず未観測時間へ積算する。

## 長時間文脈

浴槽滞在15分から30分、浴室滞在30分から60分を連続値へ変換する。閾値超過だけで医療状態を確定せず、次段の安全融合が利用する独立時間文脈として出力する。浴槽内の危険静止・危険姿勢・呼吸微動喪失も別の`bathtub_immobility`証拠として保持する。

## 公開技術との境界

連続環境でのセッション分割、時間局所性、サンプル鮮度、観測欠落を明示するという公開された一般原理だけを採用する。公開論文固有のニューラルネットワーク、学習目的、学習済み重みは複製しない。

- CSI-Bench: https://arxiv.org/abs/2505.21866
- WiFi CSI Temporal Activity Detection: https://arxiv.org/abs/2412.16233
- Age-aware CSI sensing: https://arxiv.org/abs/2606.31690

## 安全境界

本機能は入浴時間のCSI推定であり、ヒートショック診断、医療診断、救命保証ではない。危険な長時間入浴や転倒を人へ実施させる評価は行わない。
