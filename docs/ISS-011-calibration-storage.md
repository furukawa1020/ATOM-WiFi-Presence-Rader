# ISS-011 キャリブレーション成果物の永続化

## 保存対象

CalibrationArtifactは次の情報を一つの固定長成果物として保持する。

- キャリブレーションID、作成時刻
- ファームウェア互換版、特徴処理版、プロトコル版
- ノードごとの設置向き
- 無線チャネル、帯域、Receiver別のRSSI、noise floor、有効CSI率、パケット間隔
- 全サブキャリアの空室median、MAD、利用可否
- 選択サブキャリア
- 選択サブキャリア共分散の下三角成分
- 特徴スキーマ、mean、scale
- 在室・動作モデルの重み、bias、閾値
- 閾値調整結果と最終検証結果

共分散は最大24サブキャリアを対象に、行ごとの下三角順で最大300要素へ圧縮する。

## 保存前検証

保存前に成果物全体を検証する。空室基準とモデルがreadyでない場合、版や無線条件が不正な場合、設置向きが未記録の場合、非有限値がある場合は保存しない。

選択サブキャリアは空室基準内に存在し、usableで、重複していなければならない。共分散は選択数から求めた要素数と一致し、すべて有限かつ対角値が非負でなければならない。

## 二重スロット

NVS名前空間atom_calにslot_aとslot_bを置く。各blobはmagic、保存版、成果物版、blobサイズ、世代番号、CRC32を持つ。

保存手順は次のとおり。

1. 両スロットを読み、ヘッダー、CRC、成果物を検証する。
2. 最新の正常世代を特定する。
3. 最新スロットではない側へ次世代を書き込む。
4. 書込み先を再読込し、CRCと世代番号を検証する。
5. 検証成功後に保存成功を返す。

新世代の検証が失敗しても、書込み前に正常だった最新スロットは変更しない。

## 読込み

読込み時は両スロットを独立して検証する。一方だけ正常ならその成果物を使用し、両方正常なら世代番号が新しい方を使用する。欠損、サイズ不一致、保存版不一致、CRC不一致、成果物不正はスロット状態として区別する。

保存と読込みはPreferencesを使用する同期処理であり、CSIコールバックからは呼び出さない。

## 後続PR

起動時ロード、無線条件との互換確認、空室基準とモデルの一括適用、失敗時のCALIBRATION REQUIRED遷移を実装する。
