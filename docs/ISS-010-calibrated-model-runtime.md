# ISS-010 特徴スキーマ付き推論ランタイム

## 特徴スキーマ

学習と推論は、次の3値がすべて一致する場合だけ接続する。

- schema_id: 特徴の意味と並び順を識別する値
- version: 同じスキーマの互換版
- feature_count: 固定長ベクトルの要素数

CalibrationTrainerはサンプル追加前にbindFeatureSchema()を必要とする。サンプル追加後の変更は拒否され、学習済みモデルにも同じスキーマが格納される。

## 特徴ベクトル作成

CalibrationFeatureVectorBuilderは、特徴番号ごとに一度だけ値を受け付ける。範囲外、重複、NaN、無限大を拒否し、スキーマが要求する全要素が揃った場合だけreadyにする。

具体的なDetectionFeaturesの各項目と特徴番号の対応は、特徴抽出側のアダプターで一か所に固定する。学習収録と通常推論は同じアダプターを利用する。

## モデル切替

CalibratedModelRuntimeは候補モデルを次の順で処理する。

1. ready状態と特徴スキーマを検証する。
2. mean、scale、重み、bias、閾値が有限か検証する。
3. scaleが正、閾値が0から1の範囲か検証する。
4. 非アクティブ側のバッファへ候補をコピーする。
5. release/acquire同期で有効バッファ番号を切り替える。

候補が不正な場合は切替前に終了するため、それまでの有効モデルは維持される。モデル切替はCSIコールバック外で行う。

## フェイルセーフ

有効モデルがない、特徴が未完成、スキーマが一致しない、数値計算が不正になった場合は推論結果をreadyにしない。出力は初期化済みのため、在室・動作判定はいずれもfalseのままとなる。
