# ISS-027 転倒・呼吸・入浴時間の総合安全証拠

## 目的

M5ATOM送信機1台と受信機最大3台のCSI観測だけを使用し、浴室内の複数の危険兆候を時間軸の異なる連続証拠として統合する。出力は確認や通知の優先度であり、疾病、溺水、呼吸停止、ヒートショックを診断しない。

## 独立して保持する証拠

| 証拠 | 主な入力 | 分離方針 |
| --- | --- | --- |
| 床上転倒 | 衝撃、転倒後静止、洗い場位置 | ドア・物体落下候補では打ち消さない |
| 浴槽内静止 | 浴槽位置、危険静止、呼吸微動低下 | 水面外乱と測定品質低下を別出力にする |
| 危険姿勢 | 低姿勢・横臥、在室文脈 | 単独で転倒確定としない |
| 呼吸微動低下 | 呼吸追跡喪失、位置、在室文脈 | 測定不能を呼吸停止と解釈しない |
| 長時間入浴 | 浴槽区間、在室区間 | 予防的な時間文脈であり診断ではない |
| 在室状態不明 | 在室不明、測定品質低下 | 不在とはみなさない |
| 外乱候補 | シャワー、水面、換気扇、ドア、物体 | 危険度を最大15%だけ弱く補正する |

## 多時間尺度の統合

高速、中速、低速の3本の状態を持つ。高速は転倒衝撃や急な浴槽内静止、中速は危険姿勢と呼吸微動低下の共起、低速は長時間入浴と在室状態不明を受け持つ。現在値と蓄積値の双方を出力し、単一分類器の確信度へ早期に集約しない。

同じプローブ番号が再評価された場合は、そのプローブ直前の状態へ戻して再計算する。EWMA、確認継続時間、観測不能時間が二重加算されない。

## 状態遷移

状態は normal、attention、check_required、urgent、emergency_notification_recommended、measurement_unavailable の6段階とする。上昇確認は0〜8秒、解除確認は20〜30秒として、危険の取りこぼしと境界付近の往復を抑える。

物理観測が途切れたときは、直前の危険度を低速で保持する。直前が緊急相当、または危険記憶が閾値以上なら urgent 以上を維持する。measurement_unavailable は、物理観測不能が5秒以上続き、保持中の危険証拠が低い場合だけ選択する最終安全策である。

emergency_notification_recommended はローカル出力上の確認優先度であり、自動通報や医学的確定を意味しない。

## 温熱情報の扱い

M5ATOM単体のCSIから室温や湯温を測定できない。このため次を常に明示する。

- room_temperature_available = false
- water_temperature_available = false
- heat_shock_assessment_available = false
- thermal_measurement_unavailable = true

浴槽滞在10分以降は bathing_time_thermal_context を徐々に上げる。ただし、これは公的な事故予防情報に沿った確認文脈であり、体温、血圧、ヒートショックを推定するものではない。温度条件を満たしたかのように補完もしない。

## 知財境界

実装はEWMA、ヒステリシス、複数証拠の一般的な組み合わせだけで構成する。特定論文や製品の非公開コード、固有の学習済み重み、データセット由来の固有閾値は取り込まない。将来OSSを導入する場合は、ライセンスと出典を別Issueで確認する。

## 安全な評価

人を転倒させる、浴槽に沈める、呼吸を止める、危険な長時間入浴を行う評価は禁止する。無人環境、柔らかいダミー、記録済みCSI、通常動作の協力者データで各証拠を個別評価する。
