# ISS-020 低ランク背景分離とCSI革新成分

## 目的

換気扇、シャワー、水流、水面揺動など、長時間継続してサブキャリア間に相関を作る背景変動を低ランク部分空間として表現する。背景では説明できない新しいCSI変化を革新成分として独立に保持する。

## 入力

各フレームの入力ベクトルは、ロバスト正規化した振幅時間差58%と補正済み位相時間差42%を組み合わせ、サブキャリア信頼度の平方根で重み付けした最大114次元の固定長ベクトルである。

## ランク3背景部分空間

3本の基底を異なる無理数周期の正弦・余弦で決定論的に初期化する。初期化時と10回の更新ごとにGram-Schmidt法で直交正規化する。

各フレームでは次を行う。

1. 入力を第1基底へ射影し、その成分を残差から除く。
2. 残差を第2、第3基底へ順に射影してデフレーションする。
3. 3成分の射影電力を背景説明エネルギーとする。
4. 最終残差電力をCSI革新エネルギーとする。

## 更新ゲート

背景基底は学習率0.00020の逐次Oja更新でゆっくり追従する。現在の周波数領域運動量が長期平均から大きく外れず、直前の衝撃量が低い場合だけ更新する。

このゲートにより、持続するファンや水流は徐々に背景へ入り、転倒、ドア開閉、物体落下などの過渡変化は即座に背景へ吸収されにくい。

## 出力

- `background_explained_ratio`: 入力エネルギーのうちランク3背景で説明できる割合
- `innovation_motion`: 背景部分空間と直交する残差のRMS運動量

革新運動量は振幅、位相、複素比、遅延領域とともにフレーム運動量へ反映する。両指標はCRC付き観測パケットで送信し、最大3リンクの品質重み付きロバスト融合へ通す。

## 精度上の扱い

背景説明率が高いことを特定の外乱名称へ直接対応付けない。シャワー、換気扇、水流などのラベルは、持続時間、Doppler帯域、遅延広がり、周期性と組み合わせて次段で校正する。

革新運動量だけで転倒を確定しない。広帯域衝撃、転倒後静止、遅延領域変化、複数リンク同期を独立に確認する。

## M5ATOM制約

- 背景基底は3 x 114要素の固定長配列
- 射影、デフレーション、Oja更新はヒープを使用しない
- PC、クラウド、外付けセンサー、行列ライブラリは不要
