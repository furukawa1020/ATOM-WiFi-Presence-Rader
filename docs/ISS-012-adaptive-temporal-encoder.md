# ISS-012 適応型時間状態エンコーダ

## 目的

長いCSI時系列をESP32上で固定メモリかつ因果的に処理し、短期変化と長期変化を同時に表す特徴へ変換する。

## 知財上の境界

本実装は特定の第三者モデルの再実装、互換実装、精度再現を目的としない。第三者のソースコード、学習済み重み、固有データセットを含めず、一般的な入力射影、ゲート付き状態更新、固定長バッファから独立に構成する。

将来外部成果を導入する場合は、Issueを分けてライセンス、特許、利用条件を確認する。

## 状態更新

各時刻の最大16特徴を正規化・クリップし、最大8個の内部状態へ射影する。入力から状態ごとの更新ゲートを計算し、現在値をどの程度取り込むかを制御する。

retention = exp(-decay_rate * update_gate * interval_ratio)

state = retention * previous_state + (1 - retention) * projected_input

状態ごとにdecay_rateを変え、短期応答と長期応答を同じ固定長状態で保持する。出力は状態射影と入力skip接続から最大16特徴を生成する。

この方式の計算量は1ステップあたり入力数×状態数と出力数×状態数に比例し、保持メモリは時系列長に依存しない。

## ESP32向け制約

- CSI履歴を可変長保存しない。
- 内部状態は最大8個とする。
- attentionや履歴キャッシュを使わない。
- 動的メモリを使わない。
- モデル切替とNVS操作はCSIコールバック外で行う。

initializeDefaultModel()は初期収録と動作確認用の多時間スケール設定を生成する。特定の外部モデルや外部重みは使用しない。

## 状態の破棄

次の場合は古い文脈を利用しない。

- フレーム間隔が上限を超えた
- 時刻が逆行した
- 必須リンクが不健全になった
- キュードロップを検出した
- 機器移動を検出した
- 環境ドリフト指標が上限を超えた
- 状態計算が非有限になった

リセット後はwarmup_stepsを満たすまで出力をreadyにしない。理由別カウンター、直近ゲート平均、状態ノルムを診断情報として公開する。

## 永続化

キャリブレーション成果物版とNVS保存版を2へ更新し、適応型時間状態モデルをCRC対象へ追加する。旧版blobは新しいファームウェアで採用しない。
