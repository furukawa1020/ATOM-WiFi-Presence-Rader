# ISS-008 キャリブレーションセッション管理

## このPRの責務

このPRは、キャリブレーションの段階遷移、収録セッションの分離、空室基準の生成だけを担当する。分類器の学習、閾値選択、最終検証、NVSへの保存は後続PRで実装する。

## 安全上の前提

- 起動しただけでは空室学習を開始しない。
- 空室、静止、動作、外乱は別のTrainingセッションとして記録する。
- ValidationセッションはTrainingと異なるIDを使う。
- 一度台帳へ登録したセッションIDは、完了・失敗・中止にかかわらず再利用しない。
- 必須リンクの異常、パケットレート不足、キュードロップ、機器移動を検出したフレームは採用しない。
- 前回の採用フレームから急変した空室フレームは、室内変化の疑いとして採用しない。

## 空室基準

空室フレームは100 ms間隔で最大192件を固定長領域へ保持する。各サブキャリアについて有効サンプル率を確認し、centered amplitudeのmedianとMADを計算する。必要数に達しないサブキャリアはusable=falseとし、利用可能なサブキャリア数が下限未満なら基準全体を確定しない。

確定結果は既存のRobustBaselineで公開されるため、CsiPreprocessorへそのまま渡せる。

## 呼び出し順序

1. beginCalibration()でキャリブレーションIDを確定する。
2. transitionTo()でRadioSurveyから対象段階へ進める。
3. TrainingまたはValidationを明示した記述子でstartSession()を呼ぶ。
4. 空室段階では品質スナップショットと前処理済みフレームをingestEmptyFrame()へ渡す。
5. finishSession()で空室基準を確定する。
6. baseline()が非nullの場合だけ通常のロバスト前処理へ進む。

除外数と直近理由はprogress()、セッションごとの結果はsessionSummary()から取得する。
